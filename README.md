# BBT

Planning and hyperlocal weather for the BBT team — rides, runs, swims, pickleball, ski days and more — app.bbt.team.

- [DESIGN.md](DESIGN.md): scope, features, algorithms, data model, architecture.
- [DECISIONS.md](DECISIONS.md): every design decision, with dates.
- [SETUP.md](SETUP.md): accounts, tokens, secrets and the first deploy.
- `public/privacy.html`: the public privacy page (served at `/privacy`).

## The app

A Cloudflare Worker (Hono API + Better Auth, D1, KV, Queues) serving a React + TypeScript app built with Vite, also wrapped as an Android app (Capacitor).

```
worker/      API routes, auth, Web Push and Firebase delivery, scheduled job
src/         React app (pages, components, client libraries)
shared/      sports, weather, kit and ride math and API types used by both sides
migrations/  D1 schema (0001 generated by scripts/auth-schema.ts), app tables and first-run data
public/      privacy and Android download pages, service worker, manifest, icons
www/         the public home page, www.bbt.team (static files, its own Worker)
android/     the Android app: Capacitor shell and its plugin (config in capacitor.config.ts)
native/www/  the Android app's offline page
data/        seed data (start spots, club routes) and the saved API samples it came from
test/        unit tests (vitest)
scripts/     auth schema generator, local seed data, smoke tests, icon renderer, APK build
brand/, prototype/  logo sources and the v1 design prototype
```

### Run it locally

```
npm ci
cp .dev.vars.example .dev.vars   # fill in SESSION_SECRET (any long random string) and GOOGLE_CLIENT_SECRET
npm run db:migrate:local
npm run dev                      # http://localhost:8787
```

Sign in with **Continue with Google** as `BOOTSTRAP_ADMIN_EMAIL` (localhost:8787 is registered with Google), then invite others from Settings.

No network for the weather and route APIs? `npm run dev:seed` loads the saved Open-Meteo sample (moved onto the coming week) and four sample routes into the local cache.

### Checks

```
npm run lint        # Biome
npm run typecheck   # TypeScript, strict
npm test            # unit tests, including the worked examples in DESIGN.md
npm run smoke       # 93 API checks against the local dev server (creates test data locally)
npm run ui-smoke    # 36 browser checks against the local dev server (after npm run dev:seed)
```

Other scripts: `npm run build` (typecheck + production build), `npm run format`, `npm run icons` (re-render the app icons from `brand/web/bbt-logo.svg`), `npm run auth:schema` (regenerate `migrations/0001_auth.sql` after a Better Auth upgrade), `npm run cf-typegen` (refresh `worker/worker-configuration.d.ts` after changing `wrangler.jsonc` or secrets).

CI runs lint, typecheck, tests, a build and an unsigned Android build on every branch push; merging to `main` also deploys, including the signed Android app once its secrets exist (`.github/workflows/deploy.yml`, SETUP.md → 7).

### The Android app

The app is a shell around https://app.bbt.team, so web changes need no new APK. To build it yourself: Java 21 and the Android SDK (Android Studio), then `npx cap sync android && cd android && ./gradlew assembleDebug`. Bump `versionCode` / `versionName` in `android/app/build.gradle` when the native code changes.

## Prototype

`prototype/index.html` is the clickable design prototype (single file, no build needed); it was the spec for the app. To rebuild it after editing `prototype/src/app.html`: `python3 prototype/build.py`.
